# דף הנחיתה וממשק הסוכנת

שני קבצים עצמאיים לגמרי — HTML, CSS ו-JS באותו קובץ, בלי תלות
בשום ספרייה. אפשר להעתיק אותם כמו שהם לריפו של דף הנחיתה.

```
landing/index.html          →  /index.html         (דף הנחיתה)
landing/meital/index.html   →  /meital/index.html  (ממשק הסוכנת)
landing/brief/index.html    →  /brief/index.html   (אישור תשלום + אפיון)
```

הם יושבים כאן ולא בריפו של דף הנחיתה מסיבה אחת: אין לי גישה
אליו. `list_repos` מחזיר 53 מאגרים ואף אחד מהם אינו הריפו הזה.
`netlify.toml` של המערכת מסמן את התיקייה הזאת `noindex`, כדי
שלא יהיו שני עותקים מאונדקסים של אותו דף.

## דף האפיון (`/brief`)

אישור התשלום והאפיון באותו דף, כי אין חזרה אוטומטית מהסליקה
ודף תודה נפרד לא ייטען אף פעם. הקישור נשלח ידנית.

* **עובד בלי פרמטרים.** בלי `?ref=` הכותרת היא "קלטנו." ואין
  כרטיס עסקה. האפיון נפתח בדיוק אותו דבר.
* **עם `?ref=GR-77`** הדף שולף מ-`/api/order` שם פרטי, מה נקנה,
  ותאריך אספקה אמיתי — ואם השליפה נכשלת, הוא ממשיך בלעדיה.
  האפיון אף פעם לא מחכה לאימות.
* מזהה העסקה מועבר לסוכנת כמשתנה דינמי (`order_id`), וכך
  ה-webhook שאחרי השיחה מצרף את התמליל ללקוח הנכון בלי לנחש
  לפי שם.
* אירוע הפיקסל כאן הוא `BriefStarted` מותאם, ולא `Lead`. מי
  שהגיע לדף כבר שילם, וערבוב שלו עם לידים מהקמפיין מלמד את
  האופטימיזציה על הקהל הלא נכון.

`ORDER_API` בראש הסקריפט מחזיק שתי כתובות: אותו דומיין דרך
ה-proxy, ואחריו כתובת מלאה כגיבוי — ריקה כרגע.
