שני קבצים עצמאיים לגמרי — HTML, CSS ו-JS באותו קובץ, בלי תלות
בשום ספרייה. אפשר להעתיק אותם כמו שהם לריפו של דף הנחיתה.

```
landing/index.html          →  /index.html         (דף הנחיתה)
landing/meital/index.html   →  /meital/index.html  (ממשק הסוכנת)
```

הם יושבים כאן ולא בריפו של דף הנחיתה מסיבה אחת: אין לי גישה
אליו. `list_repos` מחזיר 53 מאגרים ואף אחד מהם אינו הריפו הזה.
`netlify.toml` של המערכת מסמן את התיקייה הזאת `noindex`, כדי
שלא יהיו שני עותקים מאונדקסים של אותו דף.

live · ended` — ו-`data-state` על ה-body קובע מה מוצג. אין תנאים

window.__front.state()            // המצב הנוכחי
